MINIMAL ACADEMIC WEBSITE

1. Open index.html in a web browser to preview it.
2. Open index.html in VS Code to edit.
3. Replace Your Name, position, university, about text, publication titles/authors/years/DOI URLs, and email/social links.
4. Add your own CV PDF to this folder, named cv.pdf, or remove the CV section until it is ready.
5. Create a public GitHub repository named YOUR_GITHUB_USERNAME.github.io.
6. Upload index.html and cv.pdf (if available) to the repository root.
7. In repository Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
8. Your website will appear at https://YOUR_GITHUB_USERNAME.github.io/ after deployment.

Please replace the dummy publication DOI URLs before publishing.
